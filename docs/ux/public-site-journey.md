# Draft journey: public site to investigation entry

**Status: Draft for human approval.**

1. A journalist arrives at Home and reads the headline and product explanation.
2. An illustrative investigation preview demonstrates the evidence-first interface and labels its values as sample content.
3. The visitor explores Product, How it works, For Newsrooms or About through shared navigation.
4. The visitor activates “Start investigating.”
5. `/investigate` explains that the service is not connected and offers a return link.

## Interaction states and constraints

- Mobile navigation starts closed, opens with a labeled button, exposes links and closes after navigation.
- Keyboard users can reach navigation and actions with visible focus.
- Reduced-motion users receive no essential information through animation.
- Status meaning is expressed in text as well as color.
- The current entry point is a placeholder; there is no submission, loading, error or completion state yet.
