# WhatsApp Phase 2 source-backed quick answer

## Preconditions

- Use the production WhatsApp business number with the explicitly designated, deliverable recipient.
- Record the sender-scoped case history before the first quick-answer message.
- Ensure there is no active investigation draft in the conversation.
- Deploy the API and Cloudflare webhook Worker revisions together.

## Steps

1. Send `What is the capital of Kenya?`.
2. Confirm a concise reply is labeled as a quick answer, includes at least one clickable source URL, and says it is not a full investigation.
3. Send `HISTORY`; confirm the case history is unchanged from the starting state.
4. Ask `What is Sinaps Technology?` without a URL or location. Confirm the agent asks one identity clarification and does not return an answer for a guessed entity.
5. Reply with the identifying country or public URL. Confirm a short cited overview, still without creating a case.
6. Ask Agent Zero to investigate a specific factual claim. Confirm it shows a preview and that no case starts before explicit approval.

## Expected states

- Quick factual replies contain fresh-search source URLs and no assessment language.
- Quick-answer and ambiguous-entity turns create no investigation or processing job.
- Explicit investigation requests retain the existing preview and approval boundary.
